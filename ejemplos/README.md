# Ejemplos / Examples

Textos inventados para probar la herramienta sin usar datos reales. Los cuatro cubren los casos que conviene ver: un texto con marcas típicas de IA, uno escrito a mano, y el mismo informe en `.md` y `.txt` para comprobar que no se cuenta como copia entre alumnos.

```bash
uv run detector-ia -c ejemplos -s reporte_ejemplos.csv
```
